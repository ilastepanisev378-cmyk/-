# Кофейня Сейко — V3.1

V3.1 расширяет V3 живой сценой, отношениями, 7 днями, расширенной историей, термочеком, 3 мини-играми, настройками и белым пиксельным Пузатым.

## Запуск
1. Установить зависимости из requirements.txt.
2. Запустить `run_coffee.bat`.

## Настройки
Музыка, дождь, звуки, общая громкость, typewriter, анимации и shake сохраняются в `save/progress.json`.
