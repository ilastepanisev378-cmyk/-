# Сейко — Пузатый V3.2

## Запуск
1. Распакуйте ZIP полностью в отдельную папку.
2. Запустите `run_coffee.bat`.
3. Если что-то снова упадёт — используйте `run_coffee_debug.bat`; окно терминала не закроется.

## Что исправлено
- Полностью переписан `ui.kv`: исправлены ошибки Kivy KV parser, включая строку `Widget:size_hint_y:.08`.
- Убраны вложенные однострочные KV-декларации, которые вызывали `Invalid data after declaration`.
- Убрано двойное создание слоя дождя.
- Исправлены анимации Пузатого, чтобы размер не накапливал ошибку.
- Пузатый заменён на более милый белый пиксельный дизайн.
- `purr.wav` и `receipt_printer.wav` заменены на реальные, слышимые WAV-эффекты.
- Добавлены `success.wav` и `mistake.wav`.
- Аудио-менеджер стал устойчивее к отсутствующим/повреждённым файлам.
- Настройки громкости продолжают работать.
