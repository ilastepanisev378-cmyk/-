# Кофейня Сейко — V3

Версия 3 — рефакторинг прототипа в основу инди-игры.

## Что внутри

- `main.py` — экраны, игровой цикл и UI-логика.
- `managers.py` — `UIManager`, `CharacterManager`, `MinigameEngine`, `RecipeManager`, `StoryManager`, `ReceiptNarrativeManager`, `AudioManager`, `SaveManager`.
- `ui.kv` — основной визуальный слой Kivy.
- `assets/` — музыка, фон, изображения Пузатого и короткие UI/SFX WAV.
- `save/progress.json` создаётся автоматически при запуске.
- `run_coffee.bat` — запуск с паузой терминала при ошибке.

## Новая петля игры

1. Пузатый приходит анимированно.
2. Появляется диалог печатной машинкой.
3. Игрок выбирает основу + добавку.
4. Нажимает «ЗАВАРИТЬ».
5. Случайно запускается одна из трёх мини-игр:
   - тайминг;
   - размешивание;
   - сбор ингредиентов.
6. Результат влияет на эмоцию Пузатого и текст истории.
7. Чек выползает снизу, печатается строка за строкой и получает сюжетную записку.
8. Записка сохраняется в дневник.
9. День меняется, а сюжет продолжается.

## Настройки

В меню → «НАСТРОЙКИ»:

- громкость музыки;
- громкость дождя;
- громкость SFX;
- печатная машинка;
- анимации;
- сброс прогресса.

Настройки и прогресс сохраняются в `save/progress.json`.

## ВАЖНО: спрайты Пузатого

В исходном проекте были три изображения (`cat_normal`, `cat_happy`, `cat_sad`). В V3 они скопированы и переименованы:

- `assets/puzaty_idle.png`
- `assets/puzaty_happy.png`
- `assets/puzaty_sad.png`

Точного `puzaty_purr.png` в присланном архиве не было. Поэтому V3 временно использует `puzaty_happy.png` для состояния `purr`.

### Что нужно от тебя

Если у тебя действительно есть нарисованные спрайты Пузатого, пришли:

- `puzaty_idle.png`
- `puzaty_happy.png`
- `puzaty_sad.png`
- `puzaty_purr.png`

Желательно одинаковый размер, прозрачный PNG и один и тот же масштаб персонажа.

После этого достаточно заменить четыре файла в `assets/` — логика уже написана.

## Запуск

Для Windows:

```bat
run_coffee.bat
```

Или:

```bat
python main.py
```

Если Kivy не установлен:

```bat
python -m pip install -r requirements.txt
```

Проект рассчитан на Kivy 2.3.1. Это намеренно: текущая стабильная ветка Kivy 2.x использует `kivy.core.audio.SoundLoader`; в документации Kivy 3.x уже описана миграция аудиомодуля, поэтому V3 пока фиксирует API 2.3.1.

## Следующий этап

- отдельная сцена бара с параллаксом;
- ветвящиеся выборы и скрытые отношения;
